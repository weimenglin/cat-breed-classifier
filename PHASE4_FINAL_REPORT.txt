========================================================================
PRODUCTION MODEL SPECIFICATIONS
========================================================================

OPTIMAL CONFIGURATION (Final):
- Algorithm: FilteredClassifier + Resample + Random Forest
- Trees: 500 (optimal performance/speed balance)
- Features per split: sqrt(features) = ~14 SNPs
- Depth: Unlimited (captures genomic complexity)
- Missing value handling: V1 encoding (-1 for missing, 0/1/2 for alleles)
- Class balancing: Resample filter (100% sampling rate)
- Memory requirement: 4GB recommended
- Processing time: ~30 seconds for full dataset

INPUT REQUIREMENTS:
- Format: ARFF file with V1 numerical encoding
- Features: 192 SNP loci (same as training panel)
- Missing values: Encoded as -1
- Allele values: 0, 1, 2 (homozygous/heterozygous states)
- Sample size: 1-1000+ instances supported

OUTPUT FORMAT:
- Primary: Breed prediction with confidence score
- Secondary: Probability distribution across all 26 breeds
- Confidence: Based on Random Forest vote proportion
- Uncertainty: Indicated by low confidence scores
